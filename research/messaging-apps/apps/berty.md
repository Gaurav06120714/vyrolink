# Berty — research report

**Accessed:** 2026-10-15. **Confidence:** Low–medium (undated product pages).

| Item | Finding | Label |
|---|---|---|
| Transport | BLE + mDNS for offline use; built on IPFS/libp2p ("Wesh network" protocol) | REPORTED (berty.tech, GitHub README) |
| Maturity | README warns "should not yet be used to exchange sensitive data"; an undated notice says the Android app was withdrawn pending an essential security update | REPORTED |
| Releases / audits in 2025–2026 | UNKNOWN | UNKNOWN |

**Lesson:** a general-purpose P2P stack (libp2p) is heavy for BLE-only phones. VYRO LINK's small purpose-built link protocol is the better fit (Doc 05 ADR-006).
